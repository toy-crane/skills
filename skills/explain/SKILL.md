# Explain

The user asked for an explanation, so more prose is not the answer. Draw it when
a picture shows the structure better than a sentence would: a flow, a
relationship, a state change, a shape. Render with whatever the environment
offers, cheapest first. One fact or one unfamiliar word still gets a sentence.

Do not ask the user what exactly is unclear. Guess the gap — the level, the
mechanism, why not the alternative, or just a word — and draw that. A wrong guess
gets corrected, and the correction narrows it faster than a question would.

Read the real code, docs, or sources before drawing. A diagram built from what
you already believe sets a wrong model in concrete. That is worse than not
drawing. Keep one level per view: mixing levels is what made the thing hard in
the first place. Use no analogy you cannot defend when the user pushes on it.
