# 태그로 메모 거르기

## 문제

같은 주제의 메모를 한 번에 보고 싶은데 방법이 없다.

## 사용자에게 보이는 결과

- 태그를 고르면 그 태그가 붙은 메모만 목록에 남는다.

## 승인된 범위

- `src/tags.js`의 `filterByTag(notes, tag)`.

## 수용 기준

1. 고른 태그가 붙은 메모만 돌려준다. 메모의 태그 순서와 상관없다.
2. 원래 목록의 순서를 지킨다.
3. 입력 배열을 바꾸지 않는다.

## 확정된 제약과 이유

- 메모는 모두 `createNote`로 만들어지므로 `tags`는 항상 문자열 배열이다.
- 태그는 고른 목록에서만 나오므로 대소문자가 항상 같다.
- 목록은 수백 건 이하다.

## 범위 밖

- 여러 태그 동시 선택, 태그 이름 편집.

None.
