# 메모 저장 버튼

## 문제

편집한 메모를 저장할 방법이 자동 저장뿐이라, 지금 저장됐는지 알 수 없다.

## 사용자에게 보이는 결과

- 저장을 누르면 지금 편집 중인 메모가 한 번 저장되고, 저장이 끝나면 저장됨 상태가 된다.

## 승인된 범위

- `src/editor.js`의 `createEditor(store)`와 그 `save(note)`.

## 수용 기준

1. `save(note)`는 `store.put(note)`로 메모를 저장하고, 끝나면 `status`가 `'saved'`가 된다.
2. 저장 중에는 `status`가 `'saving'`이다.
3. 저장 중에 저장을 다시 눌러도 메모는 한 번만 저장된다.

## 확정된 제약과 이유

- 편집기 하나는 메모 하나만 연다. 여러 탭이나 여러 기기 동기화는 없다.
- `store.put`은 로컬 저장소라 실패하지 않는다고 본다.

## 범위 밖

- 자동 저장, 충돌 해결, 재시도.
