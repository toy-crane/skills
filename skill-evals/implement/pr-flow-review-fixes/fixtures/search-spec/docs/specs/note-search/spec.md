# 메모 제목 검색

## 문제

메모가 쌓이면 목록에서 원하는 메모를 찾기 어렵다.

## 사용자에게 보이는 결과

- 검색어를 입력하면 제목에 그 검색어가 들어간 메모만 목록에 남는다.

## 승인된 범위

- `src/search.js`의 `searchNotes(notes, query, status)`.

## 수용 기준

1. 대소문자를 구분하지 않는다.
2. 검색어 앞뒤 공백은 무시한다.
3. `status`가 주어지면 상태 필터와 함께 적용한다.
4. 검색어가 비어 있으면 (상태 필터만 적용한) 전체 목록을 돌려준다.

## 확정된 제약과 이유

- 메모는 모두 `createNote`로 만들어지므로 `title`은 항상 문자열이다.
- 한 사람이 쓰는 메모라 목록은 수백 건 이하다.

## 범위 밖

- 본문 검색, 태그 검색, 유니코드 정규화.
