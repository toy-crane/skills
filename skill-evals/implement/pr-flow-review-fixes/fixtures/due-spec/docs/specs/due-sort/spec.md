# 마감일 순으로 메모 정렬

## 문제

마감이 가까운 메모가 목록 중간에 묻힌다.

## 사용자에게 보이는 결과

- 목록을 마감일이 빠른 순으로 볼 수 있다.

## 승인된 범위

- `src/due.js`의 `sortByDue(notes)`.

## 수용 기준

1. 마감일(`due`, `YYYY-MM-DD` 문자열)이 빠른 메모가 앞에 온다.
2. 마감일이 없는 메모(`due: null`)는 맨 뒤에 원래 순서대로 온다.
3. 입력 배열을 바꾸지 않는다.

## 확정된 제약과 이유

- 메모는 모두 `createNote`로 만들어지므로 `due`는 `YYYY-MM-DD` 문자열이거나 `null`이다.
- 목록은 수백 건 이하다.

## 범위 밖

- 시간대, 반복 마감, 다른 정렬 기준.
